# Product Requirements — Public Portfolio (TASK-PROD-001)

## 1. Vue d'ensemble
Le portfolio public est la vitrine de l'ingénieur (Othmane Ait Taleb). Il doit présenter son profil, ses compétences, ses projets et ses articles de manière moderne et responsive.

## 2. Sections du Portfolio
- **Home** : Présentation percutante (Nom, Titre, Badges de spécialités, Boutons d'action rapide).
- **About** : Résumé du parcours, formation, et objectifs de carrière.
- **Skills** : Catégorisation des compétences techniques (Backend, Frontend, DevOps, etc.).
- **Projects** : Liste des réalisations avec liens vers les détails, GitHub et démos.
- **Blog** : Articles techniques récents.
- **Contact** : Formulaire de contact fonctionnel (côté mock).

## 3. Critères d'Acceptation Globaux
- Le site doit être entièrement responsive (Desktop, Tablette, Mobile).
- Utilisation stricte du Design System v1 (couleurs, typographie, boutons).
- Temps de chargement optimal et navigation fluide via Angular Router.
