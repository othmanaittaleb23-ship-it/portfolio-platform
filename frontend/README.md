# AT Othman Portfolio - Frontend

Application web publique développée avec Angular, présentant le profil, les compétences, les projets et les articles d'un ingénieur logiciel.

## Prérequis

Assure-toi d'avoir installé sur ta machine :
- **Node.js** (version LTS recommandée)
- **Angular CLI** (`npm install -g @angular/cli`)
